# 小黑配图静态转动态流程｜生产基线

这是一份基于 2026-08 已完成项目整理的生产偏好，不是对所有项目都强制适用的模板。

## 已验证的有效做法

- 先用口播筛选小黑分镜，再进入生图。安装步骤、平台操作和长提示词展示通常用录屏更清楚；小黑负责讲抽象概念、流程转化和章节提气。
- 关键帧不是“气氛图”：每张要有清楚的主动作，并能支撑至少 4 秒的动画。
- 连贯故事先做时间线和 16:9 分镜大板，再生成全套图和视频提示词；大板是审节奏、发现空镜和统一风格的关键控制点。
- 静态图出图时提前声明首帧/尾帧用途，再让模型同时给出可执行的动态提示词，能显著减少后续图生视频跑偏。
- 白底黑线、橙色胶片、少量蓝色路径让小黑和真人教程画面容易合成，也方便后期叠加。
- 多镜头交付采用本地 HTML 页：图、时序、平台提示词与复制按钮放在一起，减少来回找素材和错配提示词。

## 当前平台偏好（会变化）

- 当前优先使用 **即梦**，提示词写中文。
- Omni 作为备选平台；用户要求时提供同动作的对应版本。
- 若平台模型、时长选项、首尾帧控制或提示词行为发生变化，不凭旧经验断言；在需要操作建议时先向用户确认当前界面/模型，或按用户明确要求核实。

## 已排除的弯路

- 不把整条教程都做成小黑动画：会挤压录屏信息，并让观众看不清真实步骤。
- 不为了“热闹”无节制加角色和装置：角色各自忙碌必须服务一个清晰主动作。
- 不使用模糊、非 16:9 的小格拼大板；每格都应能独立判断为可生成的关键帧。
- 不把商业转场做成静态摆设：至少需要一个可感知的触发、加速和输出。
- 不让生图模型承担精确中文标题；使用后期独立排字。
- 不把原小黑 Skill 中可选的圆球、长条、液体、影子、洞口或机器部件角色，当作本动态教程的默认主角。它们会让镜头之间无法认出是同一个小黑。
- 不用“无嘴”这一条代替完整角色约束：身体比例、眼睛、肢体、手脚和动画中的形变都必须一起锁定。
- 不在流程尚未验证前自动创建或自动启用 Skill。本 Skill 已由用户明确授权创建，且仅能通过显式调用使用。

## 交付前检查

- 小黑是否符合 [动态主角色锁定卡](xiaohei-motion-character-lock.md)：无嘴、无瞳孔、竖向豆形、细线四肢，且全片为同一角色。
- 是否出现横向扁团、极长条、液体融化、圆球、黑色矩形、影子/洞口角色，或拟人化手指、鞋子、服装；任一项出现即返工。
- 关键边框、卡片、人物脸、文本安全区是否稳定。
- 动作是否与口播的动词一致，而不是装饰性乱动。
- 图生视频提示词是否写明可动元素、稳定元素、时长、机位和新增物体边界。
- HTML 中每张图是否匹配正确的时序与平台提示词。
