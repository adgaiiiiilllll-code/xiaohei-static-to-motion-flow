# 小黑动态主角色锁定卡

这张锁定卡用于本 Skill 的所有默认小黑出图与图生视频。它是在 Ian 原始小黑的可变角色体系上，为 YIFEI 的「小黑动态视频」额外收束出的连续动画角色设定；不是对原 Skill 的修改。

## 唯一默认角色

**角色名：无嘴竖向豆形小黑。** 一条视频里出现的全部小黑，都是同一角色的不同动作或不同景别。

- **身体：** 纯黑实心、竖直站立的不规则豆形，顶部圆润、底部微微收窄；高度约为宽度的 1.4–1.8 倍。轮廓可以有轻微手绘不规则，但不能成为正圆、横向扁团、极细长条、矩形或液体。
- **眼睛：** 身体上半部只有两枚并列的白色圆点眼；大小接近、无瞳孔、无高光、无眼白外轮廓、无睫毛和眉毛。眼睛可因朝向轻微移动，不能变成夸张的大眼或人类眼睛。
- **脸：** 除两枚白眼外，身体表面没有任何面部线条：没有嘴、鼻、牙、舌、脸颊、耳朵或表情符号。
- **四肢：** 从身体边缘长出的细黑手绘线；手脚以简洁圆点、短弯线或小椭圆收尾。可以做拿、推、跑、跳等动作，但不画五指手掌、鞋子、袜子、衣服、帽子或其他穿戴。
- **比例：** 同一镜头内允许远近造成的大小差异，但相同景别下，角色身体比例、眼睛比例和线条粗细必须一致。多只小黑仅用肢体姿势、站位和小幅轮廓差区分，不另造新物种。

## 明确排除

以下形态不作为默认小黑，也不能在图生视频中从主角色变出：

- 横向扁团、正圆球、极长的铅笔/香肠形、黑色方块或圆柱；
- 一滩液体、影子、洞口、漏斗、机器内部黑块；
- 带白色笑嘴、唇线、鼻子、眉毛、瞳孔、眼白反光或夸张表情；
- 人类式五指手、鞋、服装、头发或配饰；
- 镜头中拉伸、压扁、融化、变身、身体长出额外部位或眼睛数量变化。

如果叙事需要“挤压、疲惫、变形”等概念，用独立道具、速度线、姿势、光效或画面构图表达；主角色的身体仍保持此锁定卡的外形。

## 即梦生图提示词前缀

把以下内容放在每一张小黑生图提示词的开头，再接场景、动作和构图要求：

> 小黑角色锁定：画面中的全部小黑是同一个无嘴竖向豆形角色。纯黑实心、顶部圆润底部微收的竖向不规则豆形身体，高约为宽的 1.4–1.8 倍；上半部只有两枚并列、大小接近的白色圆点眼，无瞳孔、无高光。细黑手绘线四肢从身体边缘长出。除眼睛外没有任何脸部线条：没有嘴、鼻、眉、耳、牙或表情。无五指手、鞋、衣服、帽子。不要画成圆球、横向扁团、细长条、方块、液体、影子、洞口或机器部件。

## 即梦图生视频追加句

把以下内容接在“发生什么”的动作描述之后：

> 角色从首帧到尾帧保持同一个小黑模型：身体轮廓、比例、两枚白点眼、细线四肢和角色数量稳定，只改变肢体姿势与已有动作；不变身、不拉伸、不压扁、不融化、不增减五官或肢体，不把小黑变成其他物体。

若用户要求固定机位或不得新增物体，继续追加：

> 固定机位；不新增、不删除或替换任何物体；现有边框、文字区和关键道具保持稳定。

## 审图规则

逐只检查，不按“整体感觉差不多”放行。以下任一项不合格，就重出或局部修图：

1. 是否只有两枚白点眼，且没有嘴与任何其他五官？
2. 是否保持竖向豆形，且不属于排除形态？
3. 四肢是否为简洁细线，而非五指手、鞋、服装？
4. 同一画面、相邻分镜、首尾帧中的小黑是否像同一个角色？
5. 视频的中间帧是否仍保持角色锁定，而非只在首帧正确？
